# **Machine-Learning**
This repository contains implementations of core Machine Learning models, developed step-by-step using both fundamental concepts and standard libraries.

**Objectives**
1) Understand the working of each ML algorithm
2) Implement models from scratch and using libraries
3) Evaluate performance using standard metrics

**Models Included**
1) Linear Regression
2) Logistic Regression (coming next)
3) Decision Trees (planned)
4) Random Forest (planned)
   
**Repository Structure**  
notebooks/ → experimentation and step-by-step learning  
src/ → clean and modular implementation of algorithms  
models/ → saved trained models  
data/ → datasets (raw and processed)  
results/ → evaluation outputs and visualizations  

**How to Run**
1) Install dependencies:  
    pip install -r requirements.txt  
2)Run the notebook or scripts inside src/  

**Future Work**
1) Add more ML algorithms
2) Hyperparameter tuning
3) Model comparison and optimization
